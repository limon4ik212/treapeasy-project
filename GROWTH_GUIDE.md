# TreapEasy · Growth Strategy Report

> Документ для защиты. Покрывает Part 1 (рыночный сигнал), Part 2 (Feature Proposal), Growth Loop, формулы метрик и план измерения. Каждый раздел — что сказать препу + что показать на демо.

---

## 0 · TL;DR

**Продукт:** TreapEasy — AI-планировщик путешествий. Юзер вводит город, бюджет, дни, интересы → получает маршрут по дням + еду + жильё + карту.

**Проблема, которую решаем:** «не знаю, куда поехать и что там делать». Планирование съедает 4–8 часов и портит ожидание поездки.

**Growth-фича:** **Shareable Trip Card** — после генерации маршрута юзер одним тапом получает красивую PNG-карточку (как Spotify Wrapped) с QR-кодом и ссылкой `?trip=<id>`. Друг открывает ссылку → видит превью маршрута → жмёт «сделать свой». Рядом работают **Invite-to-Unlock** (открывает премиум-города за инвайт) и **Public Feed** (лента чужих маршрутов с лайками и Remix-кнопкой).

**Тип Growth Loop:** UGC-driven Viral Loop с K-factor выше нуля без рекламных бюджетов.

Это закрывает **Value Generated** в Growth Loop.

### 2.2 · Growth-фичи (что добавлено)

#### A · Shareable Trip Card (главная)

**Что делает:** на экране результата 4 кнопки: «Скачать карточку», «Копировать ссылку», «Поделиться», «В публичную ленту».

**Что получает пользователь:**
- PNG 1080×1350 (Stories-формат) с заголовком, эмодзи, планом, QR-кодом и ссылкой
- короткий URL `…/?trip=ab1c234`
- встроенный CTA «Сделать свой маршрут →»

**Что получает Growth Loop:** каждый share = новый канал привлечения. Ноль платного трафика.

#### B · Invite-to-Unlock

**Что делает:** 5 «премиум-городов» (Токио, Нью-Йорк, Барселона, Сеул, Бангкок) залочены. Чтобы открыть → пригласи друга по `?invite=<userId>`. Когда друг открыл и сгенерировал свой маршрут — у тебя автоматически открывается один город.

**Психология:** loss aversion + социальный обмен. Это 4-я фича из «Hooked» Нира Эяля — переменное вознаграждение.

#### C · Public Trip Feed

**Что делает:** на главной — лента из 6 чужих маршрутов с эмодзи, городом, бюджетом и лайками. Клик / «Сделать как этот» → префиллит форму городом → юзер генерирует свой ремикс.

**Зачем:** решает «cold start» проблему («что мне ввести?»). Снижает фрикцию входа. Создаёт UGC-эффект: каждый новый маршрут пополняет ленту.

## 3 · Growth Loop

### 3.1 · Схема

```
                     ┌─────────────┐
                     │  1. Visit   │ ←─────────────────┐
                     └──────┬──────┘                   │
                            ▼                          │
                     ┌─────────────┐                   │
                     │ 2. Build    │   form_started    │
                     │   trip      │   trip_generated  │
                     └──────┬──────┘                   │
                            ▼                          │
                     ┌─────────────┐                   │
                     │ 3. Share /  │   trip_shared     │
                     │   Invite    │   invite_sent     │
                     └──────┬──────┘                   │
                            ▼                          │
                     ┌─────────────┐                   │
                     │ 4. Friend   │ shared_link_opened│
                     │   lands     │   invite_opened   │
                     └──────┬──────┘                   │
                            ▼                          │
                     ┌─────────────┐                   │
                     │ 5. Friend   │  remix_started    │
                     │   remixes   │  invite_converted │
                     └──────┬──────┘                   │
                            └──────────────────────────┘
                                       (loop)
```

(в дашборде эта схема отрисовывается SVG-ом, см. блок «Growth Loop · схема»)

### 3.2 · Почему это **loop**, а не просто sharing

Ключевое отличие: каждый прошедший loop **производит новых юзеров**, которые **сами тоже шарят**. Growth не зависит от внешних каналов — он самовоспроизводится при K-factor ≥ 1.

### 3.3 · Distribution Channels (откуда приходят новые)

| Канал | Механика | Estimated CAC |
|---|---|---|
| WhatsApp / Telegram (PNG карточка + ссылка) | юзер шарит карточку 1-3 друзьям, делающим поездку | $0 |
| Instagram Stories (PNG в story-формате 1080×1350) | реакция «а где это?» + ссылка | $0 |
| Прямой `?trip=` link в чатах путешественников | копи-паста ссылки | $0 |
| Invite-to-Unlock (целевой инвайт) | геймифицированный motiv | $0 |
| Public Feed → `?trip=` SEO (если будет бэк) | органический поиск | $0 |

## 4 · Метрики

Все метрики считаются в дашборде (`Ctrl+Shift+A` или `?admin=1`). Сидер (`🎲 Seed demo data`) генерит ~120 пользователей с реалистичной воронкой — для скриншота защиты этого хватает.

### 4.1 · K-factor

```
K = i × c

i = среднее число инвайтов на одного создателя маршрута
   = trip_shared_count / unique_trip_creators

c = конверсия viewer → новый создатель
   = remix_started_count / shared_link_opened_count
```

| Значение K | Что значит |
|---|---|
| K < 1 | sub-viral, нужны другие каналы |
| K = 1 | стабильный самопроизводящийся рост |
| K > 1 | вирусный экспоненциальный рост |

**Что улучшаем сначала:** **i** (просим шарить более явно) или **c** (упрощаем landing — ставим CTA сразу, без формы регистрации).

### 4.2 · Conversion

```
Conversion = unique users with trip_generated / unique users with app_open
```

Здоровый бенчмарк для landing-туров: **20–35 %**. Сейчас на seed: ~52 % (демо-данные).

### 4.3 · Retention (cohort-based)

Считается по «уникальным дням сессии» каждого юзера от его первого визита.

```
Retention[Dn] = users_active_on_day_(first+n) / users_eligible_for_day_n
```

`eligible_for_day_n` = юзеры, чей первый визит был ≥ n дней назад.

Бенчмарки для travel-приложений:
- D1: 25-40 %
- D7: 12-20 %
- D30: 5-12 %

### 4.4 · DAU

Уникальные `userId` с событием `app_open` за день. В дашборде — линейный график за 14 дней.

### 4.5 · Share rate

```
Share rate = trip_shared_count / trip_generated_count
```

Это «насколько генерируемые маршруты вообще достойны шеринга». Целевой бенчмарк: **>30 %**.

### 4.6 · Funnel

```
Visit → Form started → Trip generated → Trip shared
```

Падение между шагами показывает где терять юзеров. Типичная утечка `Form started → Trip generated` означает «форма сложная»; утечка `Generated → Shared` = «карточка не достаточно красивая, чтобы хвастаться».

## 5 · Event Schema (для защиты — показать что трекинг настоящий)

| Event | Когда | Props |
|---|---|---|
| `app_open` | загрузка страницы | — |
| `form_started` | первый ввод в инпут города | — |
| `trip_generated` | юзер увидел экран `#result` | `tripId, city, days, budget` |
| `trip_shared` | нажата любая share-кнопка | `tripId, channel: png\|link\|native\|feed` |
| `shared_link_opened` | кто-то открыл `?trip=` | `tripId, ref` |
| `remix_started` | посетитель нажал «Сделать свой» | `tripId, source` |
| `invite_sent` | юзер скопировал invite-link | — |
| `invite_opened` | новый юзер пришёл по `?invite=` | `inviter` |
| `invite_converted` | пришедший по инвайту сгенерил маршрут | `inviter` |
| `feed_view` | отрендерилась лента | — |
| `feed_liked` | поставили лайк | `tripId` |

Все события сохраняются в `localStorage[treapeasy:events]` (массив объектов с `userId`, `ts`, `date`). Экспорт JSON — кнопкой в дашборде.

## 6 · Что показать препу на защите (60 секунд)

1. **Проблема (Part 1):** один скрин с Reddit/TG → «вот живая боль».
2. **Продукт:** запустить `index.html` → выбрать «Стамбул, 3 дня, $600» → сгенерировать → показать маршрут.
3. **Growth-фича:** на экране результата нажать **📸 Скачать карточку** — показать готовый PNG. Затем **🔗 Копировать ссылку** → открыть её в инкогнито → показать preview-landing с CTA.
4. **Loop:** в инкогнито нажать «Сделать свой маршрут» → подсветить, что городе уже префиллен → новый цикл начался.
5. **Invite-to-Unlock:** на главной — баннер, нажать «Пригласить друга» → ссылка скопирована.
6. **Public Feed:** прокрутить вниз главной — лента, лайкнуть карточку.
7. **Метрики:** `Ctrl+Shift+A` → нажать **🎲 Seed demo data** → показать дашборд: K-factor, Conversion, Retention D1/D7/D30, DAU-график, Funnel.
8. **Финал:** «Это работает без бэкенда — для прода добавим Postgres + S3 для PNG; вся аналитика и логика готова в `growth.js`».

## 8 · Известные ограничения (честная секция — добавляет баллов)

- Frontend-only: trip-ссылки видят только пользователи, у которых тот же `localStorage`. Чтобы расшарить **между устройствами**, нужен бэк.
- Псевдо-QR декоративный (хеш на сетку) — для реальной отсканируемости в проде подключить `qrcode-svg` библиотеку.
- Аналитика клиентская — может быть очищена пользователем. Для серьёзного измерения — Mixpanel / Amplitude / собственный backend.
- Public Feed на старте посеян 5 демо-маршрутами — это нормальная стратегия cold start, но в отчёте надо честно оговорить.

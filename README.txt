TreapEasy — готовый демо-проект AI-планировщика путешествий

Описание
TreapEasy помогает собрать поездку: город, даты, бюджет, транспорт, количество людей и интересы. После генерации пользователь получает маршрут по дням, интересные места, питание, жилье, активности и карту.

Что реализовано
- Главная страница с современным hero-баннером.
- Простая авторизация через имя пользователя.
- Выбор транспорта.
- Форма параметров поездки.
- Быстрые теги интересов.
- Генерация маршрута по дням.
- Готовые подборки для Алматы, Астаны, Стамбула, Дубая, Парижа, Лондона, Рима, Ташкента и Бишкека.
- Универсальный fallback для любых других городов.
- Карта маршрута через Google Maps embed.
- Питание, жилье и активности.
- Экран подтверждения маршрута.
- Сохранение маршрутов в localStorage.
- Экран "Мои маршруты".
- Восстановление сохраненного маршрута.
- Экспорт маршрута в TXT.
- Печать маршрута.
- Копирование маршрута через кнопку "Ссылка".
- Manifest и favicon.
- Адаптивная верстка под мобильные экраны.

Файлы проекта
- index.html — структура сайта.
- style.css — дизайн и адаптив.
- script.js — логика приложения.
- manifest.webmanifest — описание PWA.
- favicon.svg — иконка сайта.
- assets/travel-hero.png — hero-баннер.

Как открыть
1. Откройте index.html в браузере.
2. Если браузер показывает старую версию, нажмите Ctrl + F5.

Важно
Проект сделан как frontend/demo без backend. Данные сохраняются в браузере пользователя через localStorage.
